## 🚀 Featured Projects

### 📋 [ChaseList](https://github.com/Uzair06/chaseList) · [Live](https://chase-list.vercel.app)
A MERN app for bookkeepers to manage clients, create monthly document checklists, share secure upload links, and review submissions.
- Clients upload PDF/JPG/PNG files through unguessable links, with no account needed
- Argon2id password hashing and HttpOnly cookie sessions
- Files are signature-validated and stored in private, encrypted S3, and bookkeepers get 60-second signed downloads
- Frontend on Vercel, API on Render
`TypeScript` `React` `Node.js` `Express` `MongoDB` `AWS S3`

### 🤖 [Claude Code Agent](https://github.com/Uzair06/claude-code-agent)
A minimal Claude Code-style AI agent built from scratch in TypeScript. It reads files, writes files and runs bash commands by looping LLM tool calls (via OpenRouter) until the task is done.
`TypeScript` `Bun` `LLM Tool Calling` `OpenRouter`

### ✈️ [FormPilot](https://github.com/Uzair06/formpilot)
An AI-assisted Chrome extension (Manifest V3) that fills Workday job applications from your resume and submits **only after you confirm**. Gemini parses PDF/DOCX resumes into structured profiles, and label-based field detection works across Workday sites. It's backed by unit and end-to-end tests.
`TypeScript` `WXT` `Gemini API` `Vitest`
